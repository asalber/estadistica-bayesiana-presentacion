Regresión lineal simple

Modelos de regresión

En Estadística se utilizan modelos de regresión para describir la relación entre una variable dependiente \(Y\) y una o varias variables independientes \(X_1, X_2, \ldots, X_n\).

En el caso de una sola variable independiente, se habla de regresión simple, y el modelo se expresa como

\[ Y = f(X) + \varepsilon, \]

donde \(f(X)\) es una función de \(X\) que describe la relación entre \(Y\) y \(X\), y \(\varepsilon\) es un término de error que refleja la variabilidad de \(Y\) que no se explica por \(X\), y que se asume que sigue una distribución normal con media cero y varianza \(\sigma^2\),

\[ \varepsilon \sim \mathcal{N}(0, \sigma). \]

Diagrama de dispersión

Para analizar la relación entre dos variables cuantitativas, debemos estudiar la variabilidad de la distribución conjunta de las dos variables. Esta variabilidad conjunta se suele representar gráficamente mediante un diagrama de dispersión. Un diagrama de dispersión se representa sobre unos ejes cartesianos, donde el eje \(X\) normalmente representa la variable independiente, y el eje \(Y\) representa la variable dependiente, y por cada par de valores \((x_i,y_j)\) en la muestra se dibuja un punto en el plano con esas coordenadas.

Diagrama de dispersión.

Ejemplo 1 El conjunto de datos peso-estatura contiene el peso y la estatura de una muestra de 200 personas mayores de 18 años. El siguiente código muestra el diagrama de dispersión de peso frente a estatura.

library(tidyverse)
df <- read_csv("datos/peso-estatura.csv")
ggplot(df, aes(x = estatura, y = peso)) +
  geom_point(color = myblue) +
  labs(x = "Estatura (cm)", y = "Peso (kg)") +
  theme_minimal()

Tipos de modelos de regresión simple

La forma de la nube de puntos en el diagrama de dispersión nos da una idea de la forma de la función \(f\) que describe la relación entre \(Y\) y \(X\).

Tipos de regresión simple.

Regresión lineal simple

Cuando \(f\) es una recta, se dice que el modelo es un modelo de regresión lineal simple, y se expresa como \[ Y = \beta_0 + \beta_1 X + \varepsilon, \]

donde \(f(x) = \beta_0 + \beta_1 x\) es una una recta que expresa la relación lineal entre \(Y\) y \(X\), y \(\varepsilon \sim N(0, \sigma).\)

Para cada valor \(x_i\) de la variable independiente, el modelo de regresión lineal simple asume que la variable dependiente \(Y\) sigue una distribución normal con media \(\mu_i = \beta_0 + \beta_1 x_i\) y varianza \(\sigma\).

La relación lineal queda determinada por dos coeficientes:

  • Término independiente \(\beta_0\). Es la media de \(Y\) cuando \(X=0\).
  • Pendiente \(\beta_1\). Es el cambio que experimenta la media de \(Y\) por cada unidad que se incrementa \(X\).

Regresión lineal en Estadística frecuentista

En Estadística frecuentista, el modelo de regresión lineal simple se estima a partir de los datos utilizando el método de los mínimos cuadrados, que consiste en encontrar los valores de \(\beta_0\) y \(\beta_1\) que minimizan la suma de los cuadrados de las diferencias entre los valores observados \(y_i\) y los valores predichos por el modelo \(\hat{y}_i = \beta_0 + \beta_1 x_i\).

Esto da lugar a la famosa fórmula de la recta de regresión lineal simple:

\[ y = \bar{y} + \frac{\sigma_{xy}}{\sigma_x^2}(x-\bar{x}), \]

donde \(\bar{x}\) y \(\bar{y}\) son las medias de \(X\) e \(Y\), respectivamente, \(\sigma_{xy}\) es la covarianza entre \(X\) e \(Y\), y \(\sigma_x^2\) es la varianza de \(X\), es decir,

\[ \beta_0 = \bar{y} - \beta_1 \bar{x} \quad \text{y} \quad \beta_1 = \frac{\sigma_{xy}}{\sigma_x^2}, \]

son dos estimaciones puntuales.

Ajuste de modelos de regresión con R

En R existen varias funciones para ajustar modelos de regresión lineal. Las más habituales son:

  • lm(). Se utiliza para variables dependientes continuas con distribución normal. Ajusta un modelo de regresión lineal utilizando el método de los mínimos cuadrados ordinarios.

  • glm(). Se utiliza para variables dependientes con distribuciones de la familia exponencial: normal, binomial, Poisson, gamma, etc. Ajusta un modelo de regresión generalizada utilizando el método de máxima verosimilitud (minimiza la log-verosimilitud).

Ajuste de un modelo de regresión lineal simple con lm()

lm()

Realiza un ajuste de un modelo de regresión lineal utilizando el método de los mínimos cuadrados ordinarios.

Parámetros:

  • formula: fórmula que especifica el modelo de regresión lineal a ajustar.
  • data: conjunto de datos que se utilizará para ajustar el modelo de regresión lineal.

Conviene recordar que la fórmula para especificar un modelo de regresión en R tiene la siguiente sintaxis:

var_dependiente ~ var_independientes

donde las variables independientes en modelos de regresión múltiple se pueden combinar con los operadores

  • + para incluir varias variables independientes sin interacción.
  • * para incluir varias variables independientes con interacción.
  • : para incluir sólo la interacción entre varias variables independientes.

Regresión lineal en Estadística bayesiana

En Estadística bayesiana, los dos coeficientes del modelo \(\beta_0\) y \(\beta_1\) son dos parámetros más del modelo, que tienen asociada una distribución que refleja la incertidumbre sobre su valor.

Si asumimos que el término de error \(\varepsilon\) sigue una distribución normal, entonces tenemos el modelo

\[ Y_i|\beta_0, \beta_1, \sigma^2 \sim N(\beta_0 + \beta_1 x_i, \sigma). \]

Al igual que para otros parámetros, asignaremos una distribución a priori a cada uno de los coeficientes, así como a la desviación típica \(\sigma\) del término de error, y actualizaremos estas distribuciones a priori con los datos para obtener las distribuciones a posteriori de cada uno de los parámetros del modelo.

Supuestos del modelo de regresión lineal simple

El modelo de regresión lineal simple se basa en los siguientes supuestos:

  1. Linealidad. La relación entre \(Y\) y \(X\) es lineal, es decir, la función \(f\) que describe la relación entre \(Y\) y \(X\) es una recta.
  2. Independencia. Las observaciones son independientes entre sí.
  3. Normalidad. El término de error \(\varepsilon\) sigue una distribución normal con media cero y desviación típica \(\sigma\).
  4. Homoscedasticidad. La varianza del término de error \(\varepsilon\) es constante para todos los valores de \(X\).

Distribución a priori de los parámetros del modelo

Como vimos, para especificar las distribuciones a priori de los parámetros del modelo podemos utilizar distribuciones no informativas o distribuciones informativas. Si disponemos de información previa sobre los parámetros del modelo, debemos utilizar distribuciones informativas para reflejar esa información previa.

Puesto que \(\beta_0\) y \(\beta_1\) son parámetros de localización, es decir, parámetros que pueden tomar cualquier valor real, una distribución a priori adecuada para estos parámetros es la distribución normal.

\[\begin{align*} \beta_0 & \sim N(\theta_0,\tau_0) \\ \beta_1 & \sim N(\theta_1,\tau_1) \end{align*}\]

Mientras que para la desviación típica \(\sigma\) del término de error, que es un parámetro de escala, es decir, un parámetro que sólo puede tomar valores positivos, una distribución a priori adecuada es la distribución exponencial o la Gamma invertida.

\[ \sigma \sim \text{Exp}(\lambda). \]

Modelo de regresión lineal simple con distribuciones a priori

Distribución de los datos

\[ Y_i|\beta_0, \beta_1, \sigma \sim N(\beta_0 + \beta_1 x_i, \sigma). \]

Distribución a priori de los parámetros

\[\begin{align*} \beta_0 & \sim N(\theta_0,\tau_0) \\ \beta_1 & \sim N(\theta_1,\tau_1) \\ \sigma & \sim \text{Exp}(\lambda) \end{align*}\]

Ejemplo 4 Para modelizar la relación entre el peso y la estatura, podemos utilizar un modelo de regresión lineal simple con las siguientes distribuciones a priori para los parámetros del modelo:

\[\begin{align*} \beta_0' & \sim N(70, 10) \\ \beta_1 & \sim N(2, 1) \\ \sigma & \sim \text{Exp}(0.5) \end{align*}\]

En este caso hemos cambiado \(\beta_0\), que sería el peso de una persona de estatura cero, algo que no tiene sentido en nuestro caso, por un término independiente centrado, \(\beta_0'\), que representa el peso de una típico de una persona de estatura media.

  • \(\beta_0'\), que sería el peso de una persona de estatura media, podemos asumir que está entre 45 y 95 kg (media de 70 kg y desviación típica de 10 kg).
  • \(\beta_1\), que sería el incremento en peso por unidad de estatura, podemos asumir que no es negativo y podría estar entre 0 y 4 kg/cm (media de 2 kg/cm y desviación típica de 1 kg/cm).
  • \(\sigma\), que mide la variabilidad de los pesos para personas de la misma estatura, no puede ser negativa y parece razonable también asumir un rango de desviaciones típicas entre 0 y 10 kg.

Validación de las distribuciones a priori

Cuando utilicemos distribuciones a priori informativas, es importante validar que estas distribuciones reflejan realmente la información previa que tenemos sobre los parámetros del modelo. Para ello, podemos simular valores de los parámetros a partir de las distribuciones a priori y comprobar que estos valores son razonables.

Ejemplo 5 Para validar las distribuciones a priori del ejemplo anterior, podemos simular 100 valores de \(\beta_0'\), \(\beta_1\) y \(\sigma^2\) a partir de sus distribuciones a priori.

library(rstan)
set.seed(123)
modelo <- "
data {
  int<lower=1> n;   // número de simulaciones (100)
}

generated quantities {
  real beta0 = normal_rng(70, 10);      
  real beta1 = normal_rng(1.5, 0.5);        
  real sigma = exponential_rng(0.5);   
}
"
prior <- stan(model_code = modelo, data = list(n = 100), iter = 200, chains = 1, algorithm = "Fixed_param")

A continuación, podemos representar gráficamente los valores simulados de cada uno de los parámetros para comprobar que estos valores son razonables.

library(tidyverse)
library(tidybayes)
prior |> 
  spread_draws(beta0, beta1, sigma) |> 
  expand_grid(x = seq(120, 220, length.out = 2)) |>
  mutate(y = beta0 + beta1 * (x - 170)) |>
  ggplot(aes(x = x, y = y, group = .draw)) +
  geom_line(color = myred, alpha = 0.2) +
  labs(title = "100 posibles rectas regresión a priori", x = "Estatura (cm)", y = "Peso (kg)")

Simulaciones de las distribuciones a posteriori

Una vez validadas las distribuciones a priori, podemos ajustar el modelo de regresión lineal simple a los datos utilizando el método de inferencia bayesiana, que nos permitirá obtener las distribuciones a posteriori de cada uno de los parámetros del modelo.

Ejemplo 6 Veamos cómo ajustar el modelo de regresión lineal simple a los datos de los pesos y las estaturas.

modelo <- "
  data {
    int<lower = 0> n;
    vector[n] Y;
    vector[n] X;
  }
  parameters {
    real beta0;
    real beta1;
    real<lower = 0> sigma;
  }
  model {
    Y ~ normal(beta0 + beta1 * X, sigma);
    beta0 ~ normal(70, 10);
    beta1 ~ normal(1.5, 0.5);
    sigma ~ exponential(0.5);
  }
"
post <- stan(model_code = modelo, 
    data = list(n = nrow(df), Y = df$peso, X = df$estatura), 
    chains = 4, iter = 5000*2, seed = 84735)

Simulaciones de las distribuciones a posteriori con el paquete rstamarm

Aunque ya hemos visto como ajustar un modelo de regresión directamente con rstan, la definición del modelo en el lenguaje de programación de Stan puede resultar algo compleja, especialmente para modelos más elaborados. Para facilitar el ajuste de modelos de regresión lineal y generalizada utilizando inferencia bayesiana, podemos utilizar el paquete rstamarm, que proporciona una interfaz más sencilla para ajustar estos modelos. En particular, utilizaremos la función stan_glm() para ajustar el modelo de regresión lineal simple a los datos.

stan_glm()

Realiza un ajuste de un modelo de regresión lineal generalizado mediante inferencia bayesiana.

Parámetros:

  • formula: fórmula que especifica el modelo de regresión lineal generalizado a ajustar. Permite especificar el modelo de regresión de forma sencilla, utilizando una sintaxis similar a la función glm() del paquete stats.
  • data: conjunto de datos que se utilizará para ajustar el modelo de regresión lineal generalizado.
  • family: familia de distribuciones que se utilizará para modelar la variable dependiente. Para un modelo de regresión lineal simple, se utiliza la familia gaussian(), que asume que la variable dependiente sigue una distribución normal.
  • prior: distribución a priori del coeficiente de regresión (la pendiente).
  • prior_intercept: distribución a priori del término independiente.
  • prior_aux: distribución a priori de la desviación típica del término de error.

Ejemplo 7 Veamos cómo ajustar el modelo de regresión lineal simple a los datos de los pesos y las estaturas utilizando la función stan_glm()

library(rstanarm)
set.seed(123)
modelo1 <- stan_glm(peso ~ estatura, data = df, family = gaussian(),
  prior = normal(1.5, 0.5),
  prior_intercept = normal(70, 10),
  prior_aux = exponential(0.5),
  iter = 5000*2, chains = 4, seed = 123)

Advertencia

La función stan_glm asume que el término independiente está centrado en la media de la variable independiente, por lo que el término independiente \(\beta_0\) representa el peso medio de una persona de estatura media, y no el peso de una persona de estatura cero.

Distribuciones a priori por defecto

Cuando no tengamos evidencias fundadas sobre los posibles valores de los parámetros, es mejor utilizar distribuciones a priori poco informativas. La función stan_glm utiliza por defecto distribuciones a priori poco informativas para los parámetros del modelo, cuando se indica la opción autoscale = TRUE en las distribuciones a priori.

Contraste de hipótesis sobre los coeficientes de regresión

En Estadística frecuentista, después de ajustar un modelo de regresión lineal, es habitual realizar el contraste de hipótesis sobre los coeficientes de regresión

Contraste sobre el término independiente

\[\begin{align*} H_0: & \beta_0 = 0 \\ H_1: & \beta_0 \neq 0 \end{align*}\]

Contraste sobre la pendiente

\[\begin{align*} H_0: & \beta_1 = 0 \\ H_1: & \beta_1 \neq 0 \end{align*}\]

Estos contrastes se realizan con el test t de Student, que se basa en la distribución t de Student, y que nos permite obtener un \(p\)-valor para cada uno de los coeficientes de regresión, que nos indica la probabilidad de obtener un valor tan extremo como el observado si la hipótesis nula fuera cierta.

En cambio, en Estadística bayesiana, el contraste de hipótesis sobre los coeficientes de regresión se realiza mediante la comparación de las distribuciones a posteriori de los parámetros con un valor nulo o con un valor específico.

Ejemplo 11 Veamos cómo realizar el contraste de hipótesis bayesiano para ver si la pendiente del modelo de regresión lineal del peso sobre la estatura es positiva.

\[\begin{align*} H_0: & \beta_1 > 0 \\ H_1: & \beta_1 \leq 0 \end{align*}\]

library(tidybayes)
modelo1 |>
  spread_draws(estatura) |>
  summarise(prob = mean(estatura > 0)) |>
  kable(col.names = "P(β1 > 0)")
P(β1 > 0)
1

Es decir, podemos afirmar casi con total certeza que la pendiente del modelo de regresión lineal del peso sobre la estatura es positiva, lo que indica que a mayor estatura, mayor peso.

Predicciones con modelos de regresión

Una de las principales utilidades de los modelos de regresión es la posibilidad de realizar predicciones sobre nuevos casos a partir de los valores de las variables independientes.

A la hora de hacer predicciones con un modelo de regresión, es importante tener en cuenta que existen dos fuentes de variabilidad que afectan a la predicción:

  • Variabilidad de los parámetros del modelo. Esta variabilidad se refleja en las distribuciones a posteriori de los parámetros del modelo, que se han obtenido a partir de la simulación mediante cadenas de Markov.
  • Variabilidad en el muestreo. Es la variabilidad asociada al término de error que viene dada por el parámetro \(\sigma\) del modelo, que también tiene una distribución a posteriori obtenida a partir de la simulación mediante cadenas de Markov.

Tipos de predicciones

Dado un nuevo caso con un valor concreto de la variable independiente \(\hat{x}\), podemos estar interesados en dos tipos de predicciones:

  • Predicción de la media de la variable dependiente para ese caso \(E[Y|\hat{X}]\). Esta predicción se obtiene a partir de la distribución a posteriori de los parámetros del modelo, y refleja la incertidumbre sobre el valor de la media de \(Y\) para ese caso. Solo tiene en cuenta la variabilidad de los parámetros del modelo, pero no tiene en cuenta la variabilidad en el muestreo.

  • Predicción de un nuevo valor de la variable dependiente para ese caso \(Y|\hat{X}\). Esta predicción se obtiene a partir de la distribución a posteriori de los parámetros del modelo y de la distribución del término de error, y refleja la incertidumbre sobre el valor de \(Y\) para ese caso. Tiene en cuenta tanto la variabilidad de los parámetros del modelo como la variabilidad en el muestreo.

Predicción de la media de la variable dependiente para un nuevo caso

Para predecir la media de la variable dependiente para un nuevo caso, basta con tener en cuenta que

\[ E[Y|\hat{x}] = \beta_0 + \beta_1\hat{x}, \]

por lo que podemos generar la distribución a posteriori de la predicción de la media de \(Y\) para ese caso aplicando esta fórmula a cada una de las simulaciones de los parámetros del modelo obtenidas mediante las cadenas de Markov.

Para ello podemos utilizar la función epred_draws del paquete tidybayes.

epred_draws

Genera una simulación de la distribución a posteriori de la predicción de la media de la variable dependiente para un nuevo caso, a partir de la distribución a posteriori de los parámetros del modelo obtenida mediante las cadenas de Markov.

Parámetros:

  • modelo1: distribución a posteriori de los parámetros del modelo obtenida mediante las cadenas de Markov.
  • newdata: nuevo caso para el que se quiere realizar la predicción, especificado como un data frame con las mismas variables independientes que el modelo de regresión.

Ejemplo 12 Veamos cómo obtener la distribución a posteriori de la predicción del peso medio para una persona de estatura 180 cm, utilizando el modelo de regresión lineal simple ajustado anteriormente.

Predicción de un nuevo valor de la variable dependiente para un nuevo caso

Para predecir un nuevo valor de la variable dependiente para un nuevo caso, debemos tener en cuenta tanto la variabilidad de los parámetros del modelo como la variabilidad en el muestreo, por lo que la distribución a posteriori de la predicción será

\[ Y|\hat{x},\beta_0,\beta_1,\sigma \sim N(\beta_0 + \beta_1 \hat{x}, \sigma), \]

Así pues, para una muestra aleatoria de esta distribución, basta con generar una simulación de esta distribución para cada una de las simulaciones de los parámetros del modelo obtenidas mediante las cadenas de Markov.

\[\begin{align*} \beta_{0,1}, \beta_{1,1}, \sigma_1 &\longrightarrow \hat{y}_1 = \text{rnorm}(1, \beta_{0,1} + \beta_{1,1} \hat{x}, \sigma_1) \\ \beta_{0,2}, \beta_{1,2}, \sigma_2 &\longrightarrow \hat{y}_2 = \text{rnorm}(1, \beta_{0,2} + \beta_{1,2} \hat{x}, \sigma_2) \\ &\vdots \\ \beta_{0,n}, \beta_{1,n}, \sigma_n &\longrightarrow \hat{y}_n = \text{rnorm}(1, \beta_{0,n} + \beta_{1,n} \hat{x}, \sigma_n) \\ \end{align*}\]

Aunque no es complicado simular esta muestra con R, podemos aprovechar la función predicted_draws del paquete tidybayes.

predicted_draws

  • modelo1: distribución a posteriori de los parámetros del modelo obtenida mediante las cadenas de Markov.

Evaluación de modelos de regresión

Todos los modelos de regresión son aproximaciones de la realidad, y por tanto, es importante evaluar la calidad del ajuste de un modelo a los datos, sobre todo si queremos hacer predicciones con ese modelo.

La manera más lógica de evaluar la calidad del ajuste de un modelo de regresión es comparar las predicciones del modelo con los valores observados en los datos, y medir la discrepancia entre ambos.

Para ello, primero debemos obtener las distribuciones a posteriori de las predicciones para cada uno de los casos de la muestra. Como ya hemos visto esto podemos hacerlo con la función predicted_draws() del paquete tidybayes.

Ejemplo 14 Veamos cómo obtener los intervalos de credibilidad de las predicciones para cada una de las estaturas del conjunto de datos, utilizando el modelo de regresión lineal simple ajustado anteriormente.

post_pred <- predicted_draws(modelo1, newdata = df, value = "Predicción")
ggplot(post_pred, aes(x = estatura, y = Predicción)) +
  stat_pointinterval(.width = c(0.5, 0.95), color = myred) +
  geom_point(data = df, aes(y = peso), color = myblue) +
  labs(x = "Estatura (cm)", y = "Peso (kg)")

Métricas de evaluación

Una vez hemos generado las distribuciones a posteriori de las predicciones para cada uno de los casos de la muestra, podemos usar las siguientes métricas para evaluar la precisión de las predicciones del modelo:

  • Error absoluto mediano (MAE). Es la mediana de los valores absolutos de las diferencias entre los valores observados y los valores predichos por el modelo.

\[ MAE = \mbox{Mediana}\{|y_i - \hat{y}_i|\} \]

  • Error absoluto mediano tipificado (\(MAE_t\)). Es la mediana de los valores absolutos de las diferencias entre los valores observados y los valores predichos por el modelo, tipificados por la desviación típica de los valores observados.

\[ MAE_t = \mbox{Mediana}\left\{\frac{|y_i - \hat{y}_i|}{\sigma_y}\right\} \]

  • Raíz del Error cuadrático medio (RMSE). Es la media de los cuadrados de las diferencias entre los valores observados y los valores predichos por el modelo.

\[ RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2} \]

  • Cobertura de los intervalos de credibilidad de las predicciones. Es la proporción de casos de la muestra para los que el valor observado se encuentra dentro del intervalo de credibilidad de las predicciones del modelo. Se puede hacer para distintos niveles de credibilidad, por ejemplo, 50%, 90% y 95%.

  • Coeficiente de determinación bayesiano \(R^2\). Es la proporción de la variabilidad total de los valores observados que es explicada por el modelo de regresión.

\[ R^2_{\mbox{Bayes}} = \frac{\mbox{Var}(\hat{y})}{\mbox{Var}(\hat{y}) + \mbox{Var}(y - \hat{y})} \]

Existen diferentes paquetes de R que permiten calcular estas métricas de evaluación de modelos de regresión.

Para calcular el error absoluto mediano, el error absoluto mediano tipificado y los intervalos de cobertura, podemos usar la función prediction_summary() del paquete bayesrules.

Evaluación del modelo de regresión en datos nuevos

En general, un modelo de regresión ajustado a un conjunto de datos se ajustará mejor a esos datos que a otros datos nuevos. Este problema se conoce como sobreajuste (overfitting).

Cuando hay sobreajuste de un modelo de regresión, las medidas de precisión del modelo evaluadas sobre el propio conjunto de datos sobreestiman la capacidad predictiva del modelo, por lo que es importante evaluar la capacidad de predicción del modelo en datos nuevos. Para ello se suele dividir el conjunto de datos en dos subconjuntos:

  • Conjunto de entrenamiento. Se utiliza para ajustar el modelo de regresión y obtener las distribuciones a posteriori de los parámetros del modelo.
  • Conjunto de prueba. Se utiliza para evaluar la precisión del modelo.

Esta división permite ajustar el modelo de regresión a partir del conjunto de entrenamiento y evaluar la precisión del modelo en el conjunto de prueba, que no se ha utilizado para ajustar el modelo.

Validación cruzada

Realizar la evaluación de un modelo de regresión con un conjunto de datos nuevos, sin duda dará una estimación más realista de la precisión predictiva del modelo. Para que esta estimación sea más fiable, es recomendable repetir el proceso varias veces con distintos conjuntos de entrenamiento y prueba, y calcular la media de las métricas de evaluación obtenidas en cada repetición.

La validación cruzada se basa en esta idea y consiste en dividir el conjunto de datos en \(k\) subconjuntos llamados pliegues (folds), y realizar \(k\) iteraciones. En cada iteración se reserva uno de los \(k\) subonjuntos como conjunto de prueba y se ajusta el modelo de regresión con los \(k-1\) subconjuntos restantes, que forman el conjunto de entrenamiento. En cada iteración se calculan las métricas de evaluación del modelo en el conjunto de prueba, y al final se calcula la media de estas métricas a lo largo de las \(k\) iteraciones.

Regresión lineal múltiple

Regresión lineal múltiple

Cuando la variable dependiente \(Y\) depende de varias variables independientes \(X_1, X_2, \ldots, X_p\), se habla de regresión lineal múltiple:

\[ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \varepsilon, \quad \varepsilon \sim N(0, \sigma). \]

El procedimiento para ajustar un modelo de regresión lineal múltiple mediante inferencia bayesiana es el mismo que para un modelo de regresión lineal simple, solo que con más parámetros a estimar y de los que debemos especificar sus distribuciones a priori

Ejercicio 1 ¿Qué modelo de regresión lineal múltiple ajustarías para modelizar el peso de una persona en función de su estatura y su sexo? ¿Qué distribuciones a priori utilizarías para los parámetros del modelo?

Solución

Antes de nada, puesto que el sexo es una variable categórica, debemos codificarla como variable númerica para poder introducirla en el modelo de regresión múltiple. Como en este caso solo hay dos categorías posibles, podemos usar el 0 para hombres y 1 para mujeres.

Si llamamos \(X_1\) a la estatura y \(X_2\) al sexo, el modelo de regresión lineal múltiple sería:

\[ Y|\beta_0, \beta_1, \beta_2, \sigma \sim N(\beta_0 + \beta_1 X_1 + \beta_2 X_2, \sigma) \]

De esta manera, para cada categoría de sexo, el modelo de regresión lineal múltiple nos da una recta de regresión distinta:

Recta de regresión de hombres (\(X_2 = 0\))

\[ Y = \beta_0 + \beta_1 X_1 + \varepsilon \]

Recta de regresión de mujeres (\(X_2 = 1\))

\[ Y = (\beta_0 + \beta_2) + \beta_1 X_1 + \varepsilon \]

Solución (continuación)

Este modelo asume que la pendiente de la recta de regresión es la misma para hombres y mujeres, pero que el término independiente es distinto.

Para las distribuciones a priori de los parámetros \(\beta_0, \beta_1\) y \(\sigma\), podemos utilizar las mismas distribuciones a priori que en el modelo de regresión lineal simple.

Y para la distribución a priori de \(\beta_2\) podemos usar una distribución normal que refleje la diferencia de peso entre hombres y mujeres, que sabemos por experiencia que es positiva. Por ejemplo, \(\beta_2 \sim N(-10, 5)\), que refleja que la diferencia de peso entre hombres y mujeres de la misma estatura es de unos 10 kg, con una desviación típica de 5 kg.

Evaluación de las distribuciones a priori

Como ya vimos con los modelos de regresión simple, antes de hacer el ajuste del modelo, conviene evaluar las distribuciones a priori de los parámetros del modelo para comprobar que son razonables. Para ello podemos simular valores de los parámetros a partir de sus distribuciones a priori y dibujar las rectas de regresión correspondientes.

Recordemos que podemos usar la misma función stan_glm para simular las distribuciones a priori de los parámetros del modelo, añadiendo la opción prior_PD = TRUE.

Ejemplo 18 Veamos cómo simular las distribuciones a priori de los parámetros del modelo de regresión lineal múltiple del peso sobre la estatura y el sexo.

library(rstanarm)
set.seed(123)
modelo2_prior <- stan_glm(
  peso ~ estatura + sexo,
  data = df,
  family = gaussian(),
  prior_intercept = normal(70, 10),
  prior = normal(location = c(1.5, -10), scale = c(0.5, 5)),
  prior_aux = exponential(0.5),
  chains = 4, iter = 5000 * 2, seed = 123,
  prior_PD = TRUE
)

Advertencia

La función stan_glm realiza la codificación de las variables categóricas de forma automática y asigna el código 0 a la primera categoría alfabéticamente y el código 1 a la segunda categoría.

A continuación podemos dibujar algunas de las rectas de regresión obtenidas a partir de la simulación de las distribuciones a priori de los parámetros del modelo para ver si son razonables.

Comparación de modelos de regresión

En general, cuantas más variables independientes agreguemos a un modelo de regresión múltiple, mayor será el coeficiente de determinación ya que la variabilidad no explicada por el modelo disminuirá. No obstante, esto no significa que el modelo sea mejor, ya que al aumentar el número de variables independientes, también aumentará el sobreajuste al conjunto de entrenamiento.

Para comparar la capacidad predictiva de distintos modelos de regresión, podemos utilizar la métrica de la densidad logarítmica predictiva esperada (ELPD), que penaliza la complejidad del modelo y nos permite comparar modelos de regresión con distinto número de variables independientes.

Densidad logarítmica predictiva esperada (ELPD)

Esta métrica mide el logaritmo de la densidad predictiva puntual de los valores observados en los datos de prueba, según la distribución predictiva del modelo ajustado a los datos de entrenamiento.

Normalmente se utiliza validación cruzada de \(n\) pliegues, conocida como leave-one-out cross-validation (LOO-CV), de manera que se realiza una iteración por cada caso de la muestra, reservando ese caso como conjunto de prueba y ajustando el modelo con el resto de los casos como conjunto de entrenamiento.

Para cada caso \(y_i\) de la muestra \((y_1, y_2, ..., y_n)\), se calcula el logaritmo de la densidad predictiva de \(y_i\) según la distribución predictiva del modelo ajustado a los datos de la muestra menos \(y_i\):

\[ \mbox{lpg}_i = \log p(y_i|y_{-i}) = \log \int p(y_i|\theta)p(\theta|y_{-i})d\theta, \]

donde \(y_{-i}\) es el conjunto de datos sin el caso \(y_i\), \(p(y_i|\theta)\) es la densidad predictiva esperada para el valor \(y_i\) dado los parámetros del modelo \(\theta\), y \(p(\theta|y_{-i})\) es la distribución a posteriori de los parámetros del modelo ajustado a los datos de entrenamiento.

Finalmente, la densidad logarítmica predictiva esperada (ELPD) se calcula como la suma de los logaritmos de las densidades predictivas de todos los casos de la muestra.

Definición 1 (Densidad logarítmica predictiva esperada (ELPD)) Dada una muestra de datos \((y_1, y_2, ..., y_n)\), la densidad logarítmica predictiva esperada (ELPD) de un modelo de regresión con parámetros \(\theta\), ajustado a los datos de entrenamiento mediante validación cruzada LOO-CV se define como

\[ \mbox{elpd} = \sum_{i=1}^n \log p(y_i|y_{-i}) = \sum_{i=1}^n \log \int p(y_i|\theta)p(\theta|y_{-i})d\theta, \]

donde \(y_{-i}\) es el conjunto de datos sin el caso \(y_i\), \(p(y_i|\theta)\) es la densidad predictiva esperada para el valor \(y_i\) dado los parámetros del modelo \(\theta\), y \(p(\theta|y_{-i})\) es la distribución a posteriori de los parámetros del modelo ajustado a los datos de entrenamiento.

Cuanto mayor sea el valor de la ELPD, mejor será la capacidad predictiva del modelo, por lo que podemos comparar distintos modelos de regresión mediante esta métrica.

Podemos calcular la ELPD de un modelo de regresión bayesiano ajustado con stan_glm mediante la función loo del paquete rstanarm.

loo

Calcula la densidad logarítmica predictiva esperada (ELPD) de un modelo de regresión bayesiano ajustado con stan_glm mediante validación cruzada LOO-CV.

Parámetros:

  • x: modelo de regresión bayesiano ajustado con stan_glm.

La diferencia de ELPD entre ambos modelos es

La función loo_compare del paquete rstanarm permite comparar la ELPD de varios modelos de regresión bayesianos ajustados con stan_glm.

loo_compare

Compara la densidad logarítmica predictiva esperada (ELPD) de varios modelos de regresión bayesianos ajustados con stan_glm.

Parámetros:

  • x: lista de ELDPs de los modelos a comparar calculados con loo.

Ejemplo 26 Veamos cómo comparar la ELPD de los modelos de regresión lineal simple y múltiple ajustados anteriormente.

loo1 <- loo(modelo1)
loo2 <- loo(modelo2)
loo_compare(loo1, loo2)[,c("elpd_diff", "se_diff")] |> kable()
elpd_diff se_diff
modelo2 0.0000 0.000000
modelo1 -28.6676 6.156593

En este caso la diferencia tipificada de ELDP es

\[ \frac{\Delta \mbox{ELPD}}{\mbox{SE}(\mbox{ELPD})} = \frac{28.7}{6.2} \approx 4.7 \]

Se suele utilizar la regla de Vehtari:

  • \(\Delta \mbox{ELPD} / \mbox{SE}(\mbox{ELPD}) < 2 \rightarrow\) Diferencia no sustancial.
  • \(2\leq \Delta \mbox{ELPD} / \mbox{SE}(\mbox{ELPD}) < 4 \rightarrow\) Diferencia moderada.
  • \(\geq 4 \rightarrow\) Diferencia sustancial.

En este caso podemos decir que el modelo de regresión múltiple es sustancialmente mejor que el modelo de regresión simple.
